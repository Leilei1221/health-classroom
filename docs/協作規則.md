# 協作規則・Claude Code × Codex

本專案由兩個 AI 輪流開發，蕾蕾老師負責調度與確認。
**兩個 AI 不會直接溝通，這份文件和 `docs/工作日誌.md` 就是彼此交接的管道。**

每次開工前，請先讀這份文件和工作日誌的最後三筆。

---

## 一、分工

依風險分，不依功能大小分。

| 誰 | 負責 | 理由 |
|---|---|---|
| **Claude Code** | 動到資料庫結構、RLS、trigger、紅旗、刪除資料的工作 | 需要嚴格驗證、改錯代價高 |
| **Codex** | 純前端畫面、排版、串接既有資料、列印樣式 | 改錯了不合併就好，不影響資料 |

### 剩餘工作分配

| # | 項目 | 誰做 | 動資料庫？ |
|---|---|---|---|
| 0 | 確認上週 72 筆重進結果頁能否看到新文案（只回答） | Codex | 否 |
| 1 | 生活型態 10 題接建議庫 | Codex | 否 |
| 2 | 學生端分析頁 | Codex | 否 |
| 3 | 教師端百分位與班級分布 | Codex | 否 |
| 4 | SMART 目標：`hc_health_goal` 表 + RLS | **Claude Code** | 是 |
| 4b | SMART 目標：六步精靈畫面與兩道可行性檢查 | Codex | 否（接 4 的表） |
| 5 | 四週打卡：`hc_health_checkin` 表 + RLS | **Claude Code** | 是 |
| 5b | 打卡頁畫面 | Codex | 否（接 5 的表） |
| 6 | 教師端打卡看板 | Codex | 否 |
| 7a | 期末歷程 PDF（列印樣式） | Codex | 否 |
| 7b | 學期結算（清資料） | **Claude Code** | 是，且待輔導室確認 |

**原則：資料庫先由 Claude Code 建好並驗證，Codex 再接畫面。** 不要反過來。

---

## 二、分支規則

- **main 是學生正在用的版本，任何 AI 都不可以直接改 main**
- 每一項工作開一個新分支，命名：`誰-項目`，例如 `codex-analysis-page`、`claude-goal-table`
- 兩個 AI **不可以同時動同一個檔案**。開工前看工作日誌，若另一方的分支還沒合併且動到同一個檔，先停下來問蕾蕾老師
- 合併由蕾蕾老師決定

### 存檔點

`claude-handoff-2026-09-21` 是 Claude Code 交班時的確定可用版本。改壞時回到這裡。

---

## 三、交叉檢查

兩個 AI 輪流的好處是可以互相檢查。

- **每次開工的第一件事**：讀工作日誌最後一筆，檢查上一個 AI 做的東西。發現問題先回報，不要直接改掉對方的程式
- Codex 做完的分支，合併前可以請 Claude Code 看一次（反之亦然）
- 跑全部回歸測試，任何一項從通過變成失敗，要在日誌裡寫清楚

---

## 四、工作日誌格式

**每做完一步，在 `docs/工作日誌.md` 最上方新增一筆**（最新的在最上面）：

```markdown
## 2026-09-XX｜Codex｜第 2 項 學生端分析頁

**分支**：codex-analysis-page
**狀態**：完成，待蕾蕾老師確認合併

**做了什麼**：
- （白話，三到五點）

**動到的檔案**：
- src/health/xxx.tsx（新增）
- src/health/yyy.ts（修改）

**沒動到的檔案**（確認用）：
- riskLevel.ts、riskCopy.ts 未修改

**資料庫**：無變更 ／ 或：新增 migration xxx.sql，已附還原 SQL

**測試**：
- 新增 analysis 測試 N 項，全過
- 回歸：flag4 52、detail 93……全過 ／ 或：某項失敗，原因……

**發現的問題或疑問**：
- （留給下一個接手者或蕾蕾老師）

**下一步**：
- （建議誰做什麼）
```

`動到的檔案` 和 `沒動到的檔案` 兩欄都要寫。蕾蕾老師靠這兩欄判斷能不能合併。

## 五、鎖定清單

以下檔案任何 AI 都**不可修改**，除非蕾蕾老師明確同意並寫進日誌：

- `riskLevel.ts`
- `riskCopy.ts`
- 名稱含 `risk` 的 migration 與 trigger
- `hc_health_risk_review()`
- `docs/學生端分析頁_建議庫內容.md`
- `docs/課本檢測_等第對應與紅旗處理規格.md` 第五節

## 六、每週節奏（參考）

Claude 額度每週三重置。

| 時段 | 誰 | 做什麼 |
|---|---|---|
| 週三～週四 | Claude Code | 先檢查 Codex 上週的分支，再做本週資料庫工作 |
| 週四～下週二 | Codex | 接 Claude Code 建好的表做畫面 |
| 隨時 | Claude（對話） | 規格、文案、判斷、看截圖把關 |
