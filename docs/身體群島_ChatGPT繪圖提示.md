# 身體群島・ChatGPT 繪圖提示

頁面：`/health/island`（教師預覽：`/health/island/preview`）。程式碼在 `src/health/island/`。
目前每座島先用程式畫的向量圖代替。圖畫好以後放進 `src/assets/island/`，在 `BodyIslands.tsx` 的 `ISLAND_ART` 補上對應的 id，那座島就會換成新圖。

## 怎麼用

1. 在 ChatGPT 開**同一個對話**，先貼「共同風格」那一段，請它記住。
2. 一次貼一座島的提示，一座島一張圖。**同一個對話裡畫完全部六座**，風格才會一致。
3. 每張圖下載成 PNG，照下表的檔名存好，交給 Claude 或 Codex 放進程式。
4. 如果背景不是透明的，請 ChatGPT「把背景改成透明，只留島」。

## 共同風格（每次開新對話先貼這段）

```
我要畫一組 6 張的「身體群島」插圖，給高中健康與護理課的手機網頁用。請記住以下共同規格，之後每一張都要遵守：

- 一張圖只畫一座小島，正方形 1024×1024，背景完全透明（PNG）
- 等角視角（isometric），從右前上方約 30 度往下看，光從左上方來
- 島是圓潤不規則的形狀，邊緣有一圈淺沙灘和一點點淺水，底下看得到泥土斷面
- 島的大小約占畫面寬度的 75%，置中，四周留白
- 風格：柔和的低多邊形／黏土質感 3D 插畫，可愛、乾淨、不寫實；粉彩配色，飽和度低
- 島上的建築和物件要小巧、像模型，數量 3～6 個，不要擠滿
- 不要出現任何文字、數字、字母、標誌或浮水印
- 不要畫人物的臉部特寫，也不要畫真實的人體器官解剖圖（不要血、不要內臟寫實細節）
- 6 張的視角、光線、比例、筆觸要一致，像同一套模型
```

## 各島提示

### 1. 腦與心島（brain.png）

```
第 1 張：腦與心島。主色是淡紫色（#CFC1EA）。
島的中央是一棟圓頂建築，屋頂的弧線像大腦的皺褶（抽象、可愛，不寫實）。
旁邊有：一間亮著小夜燈、窗邊掛著月亮的小屋（代表睡眠）；一支溫度計造型的小塔（代表心情溫度計）；一座小涼亭，裡面放著一本打開的日記本（代表感恩日記）。
島上有幾條發光的細線從圓頂延伸出去，像神經在傳遞訊號。整體氣氛安靜、放鬆。
```

### 2. 心肺島（cardio.png）

```
第 2 張：心肺島。主色是淡珊瑚粉（#F2B8B0）。
島的中央是一座愛心造型的抽水站（可愛的建築，不是真的心臟），有紅色和藍色兩條小水道從它往外繞一圈再流回來，代表血液循環。
抽水站後面有兩棵左右對稱、樹冠蓬鬆的大樹，形狀讓人聯想到兩片肺。
旁邊有一個小小的血壓計造型路標，和一個跳動波形造型的小拱門（代表脈搏）。
```

### 3. 消化島（digest.png）

```
第 3 張：消化島。主色是淡奶油黃（#F9D27E）。
島上有一條彎彎曲曲、繞了好幾圈的小河（代表腸道，抽象表現，不寫實），河的起點是一座碗形的小廣場。
島上有一座小農田和菜園、一個水果攤、一張擺著六格餐盤的野餐桌（代表六大類食物）。
小河旁邊有幾個小小的水車，把養分往外送。
```

### 4. 能量代謝島（metab.png）

```
第 4 張：能量代謝島。主色是淡杏橘色（#F9C79B）。
島的中央是一座可愛的小發電廠，煙囪冒出淡淡的、像小火苗的暖光（不是黑煙）。
旁邊有一座小倉庫，裡面堆著圓滾滾的金黃色儲物桶（代表身體把用不完的能量存起來）。
還有一個大大的體重計造型平台，和一條捲尺造型的小路繞著島邊。
```

### 5. 肌肉骨骼島（muscle.png）

```
第 5 張：肌肉骨骼島。主色是淡草綠色（#BFE3A8）。
島上有一座小小的戶外運動場：跑道、一組啞鈴造型的雕塑、一座攀岩牆。
島的一側有一座用白色柱子和弧形樑搭起來的小涼亭，結構讓人聯想到骨架（抽象，不要畫真的骨頭或骷髏）。
整體感覺有活力、充滿運動氣氛。
```

### 6. 出發港（harbor.png）

```
第 6 張：出發港。主色是淡天藍色（#A9D6EE）。
這座島是一個小港口：一座白色小燈塔、一條木頭碼頭，碼頭邊停著一艘小帆船。
港口旁邊有一棟小小的航海辦公室，門口有一塊空白的告示板（上面不要有字），和一張攤開的地圖。
感覺是一切旅程出發的地方，溫暖、歡迎。
```

## 可選：海面背景（sea.png）

不一定要。現在的海是程式畫的漸層加波紋，已經可以用。

```
第 7 張（可選）：海面背景。直式 720×1200，不要透明。
從正上方往下看的平靜淺海，粉藍色漸層，上淺下深，有很淡的波紋和幾道柔和的反光。
畫面中央有一個用淺色淺灘隱約排成的人形輪廓（站立、雙手微微張開），輪廓要很淡，像沙洲，不要畫出臉或任何身體細節。
不要有任何島、船、文字。風格和前面 6 張一致。
```

## 檢查清單（收圖時看一下）

| 項目 | 標準 |
|---|---|
| 背景 | 透明（海面背景除外） |
| 文字 | 完全沒有任何字，包括招牌上的字 |
| 器官 | 沒有寫實的器官、血、骨頭或骷髏 |
| 一致性 | 6 張的視角和光線方向相同 |
| 大小 | 島大約占畫面寬度的 3/4，置中 |
