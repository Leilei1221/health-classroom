# 課本自我檢測・等第對應與紅旗處理規格

四項檢測的實際選項、計分與對應處理。心理健康那三項（P224、P232、P247）是本專案**安全性最高**的一段，請完整照做。

課本出處：育達版健康與護理，P14、P224、P232、P247。

# 一、生活型態檢視（P14）

改編自青少年健康促進量表（Adolescent Health Promotion Scale）。

## 題目與選項

10 題，每題三選一：

| 選項 | 定義 | 落區 |
|---|---|---|
| 經常做到 | 一週 3 次以上 | 綠燈區・健康 ALL PASS |
| 偶爾做到 | 一週 1-2 次 | 黃燈區・健康警示 |
| 從未做到 | — | 紅燈區・健康加強 |

| # | 題目 | 對應建議庫 trigger |
|---|---|---|
| 1 | 除體育課外，我每週至少運動 3 次，每次至少 30 分鐘為基準 | `exercise_under_1h` |
| 2 | 我盡量找機會運動（例如：用走樓梯代替電梯或多走路） | `sedentary` |
| 3 | 我有每天吃早餐的習慣 | `skip_breakfast` |
| 4 | 我每天都吃五蔬果 | `veg_under_3` |
| 5 | 我每天喝 1,500 c.c. 以上的開水 | `water_under_target` |
| 6 | 我每天睡 7 小時以上 | `sleep_6_7`（偶爾）/ `sleep_under_6`（從未） |
| 7 | 我可以在躺床 20 分鐘以內入睡 | `sleep_onset` |
| 8 | 當身體不適時，我會盡快去看醫生 | 無對應建議，僅計入落區 |
| 9 | 我會限制糖分與甜食的攝取 | `sugar_drink` |
| 10 | 我很少吃油炸與高熱量食物 | `fried_food` |

## 觸發規則

- 「從未做到」→ 該題 trigger 觸發，權重高
- 「偶爾做到」→ 該題 trigger 觸發，權重低
- 「經常做到」→ 不觸發

分析頁第 ② 區選優先改善項目時，先取紅燈區的題目，不足再取黃燈區。

## 建議庫要補的兩個 trigger

`sleep_onset`（躺床 20 分鐘睡不著）→ 對應既有的 sleep-04（15 分鐘原則）、sleep-05（4-7-8 呼吸法）
`fried_food`（常吃油炸高熱量）→ 對應既有的 diet-02、diet-03

# 二、心情溫度計・簡式健康表 BSRS-5（P224）

資料來源：李明濱醫師。

## 題目與計分

請回想**最近一週（包括今天）**，各問題造成困擾或苦惱的程度：
0 完全沒有｜1 輕微｜2 中等程度｜3 厲害｜4 非常厲害

| # | 題目 | 計分 |
|---|---|---|
| 1 | 睡眠困難，譬如難以入睡、易醒或早醒 | 計入總分 |
| 2 | 感覺緊張不安 | 計入總分 |
| 3 | 覺得容易動怒 | 計入總分 |
| 4 | 感覺憂鬱、心情低落 | 計入總分 |
| 5 | 覺得比不上別人 | 計入總分 |
| ★ | 有自殺的想法 | **獨立判定，不計入前 5 題總分** |

## 課本判讀

| 前 5 題總分 | 課本說明 |
|---|---|
| 0-5 | 一般正常範圍 |
| 6-9 | 輕度情緒困擾：建議找親友談談，抒發情緒 |
| 10-14 | 中度情緒困擾：建議尋求心理衛生或精神醫療專業諮詢 |
| 15 以上 | 重度情緒困擾：建議尋求精神醫療專業諮詢 |

★ 自殺想法評分 **2 分以上（中等程度）** 時：建議尋求精神醫療專業諮詢。

> **【2026-09-20 蕾蕾決定】★ 這一題維持紙本課堂施測，線上不收、不存。**
> 因此下面第五節的 L3 只有「情緒檢視表第 20 題答是」一條偵測路徑。
> 程式裡不留一個永遠不會觸發的條件。

# 三、壓力偵測站（P232）

資料來源：衛福部國健署健康九九+。12 題勾選，計「符合」項數。

| 符合項數 | 課本說明 |
|---|---|
| 3 項以下 | 壓力指數還在能負荷的範圍 |
| 4-5 項 | 壓力滿困擾你，雖能勉強應付，但必須認真學習壓力管理，同時多與良師益友聊一聊 |
| 6-8 項 | 壓力很大，趕快去看心理衛生專業人員，接受系統性的心理治療 |
| 9 項以上 | 壓力已很嚴重，應該看精神專科醫師 |

# 五、紅旗判定（三個量表整合）

**這是整個系統最重要的一段。**

## 四個等級

| 等級 | 觸發條件（任一成立） | 學生端 | 教師端 |
|---|---|---|---|
| **L3 立即** | 情緒檢視表第 20 題答「是」<br>（★自殺想法題走紙本，線上不收，見第二節） | 固定關懷文案 A ＋求助管道<br>**不顯示分數、不顯示等第、不給任何生活習慣建議** | 最高層級標示，當天要處理 |
| **L2 需關注** | BSRS-5 前 5 題 ≥ 15<br>或 情緒檢視表 ≥ 12<br>或 壓力 ≥ 6 項 | 固定關懷文案 B ＋求助管道<br>不給生活習慣建議 | 標示需關注 |
| **L1 留意** | BSRS-5 6-14<br>或 情緒檢視表 6-11<br>或 壓力 4-5 項 | 溫和提示文案 C ＋鼓勵找人談<br>**可以**同時顯示壓力領域的建議 | 列入名單 |
| **L0 一般** | 其餘 | 正常走建議庫 | 無 |

**取最高級。** 三個量表分別落在不同等級時，以最高者為準。

> **【2026-09-20 蕾蕾修正】L1 的 BSRS-5 由「10-14」改為「6-14」。**
> 課本寫 6-9 是輕度情緒困擾、建議找親友談談，另外兩個量表的 L1 都對齊課本，
> 只有這個沒有。修正後三個量表一致。本校有 12 人落在這一段。

## 資料欄位

```sql
alter table hc_health_selfcheck
  add column risk_level smallint default 0  -- 0-3
      check (risk_level between 0 and 3),
  add column risk_flagged_at timestamptz,
  add column risk_reviewed boolean default false,   -- 老師已處理
  add column risk_reviewed_at timestamptz,
  add column risk_outcome text,      -- needs_support | observed_ok | joking | 其他
  add column risk_note text;         -- 老師的一行備註，只有授課教師看得到
```

`risk_level` 由送出時即時計算後寫入，不是查詢時現算——**這是要留紀錄的判定，不是可變的呈現**。

## 絕對不可以做的事

1. **絕不由 AI 生成任何回應文字。** L1-L3 的文案全部是固定字串，寫在程式裡。
2. **不在學生端顯示「你可能有憂鬱症」之類的字。** 這些是篩檢工具，不是診斷。
3. **不在學生端顯示分數或等第。** 看到「你 16 分，重度」對一個 17 歲的人沒有幫助，只有傷害。
   **範圍：只蓋掉心理檢測那三份**（心情溫度計、壓力偵測站、情緒自我檢視表）的分數與分級。
   生活型態、85210、飲食金字塔、睡眠檢測照常顯示自己的結果——那些不是心理篩檢分數，
   一起蓋掉只會讓學生以為系統壞了。（2026-09-20 蕾蕾確認）
4. **L2、L3 不顯示任何生活習慣建議。** 這時候給「多吃蔬果」是荒謬的。
5. **不寄自動通知信給學生。**
6. **不在班級進度表（投影頁）顯示任何心理紅旗。**
