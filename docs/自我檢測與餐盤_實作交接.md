## 4. 照現有寫法接資料庫

`src/health/api.ts` 已有的 `getMeasurement` / `saveMeasurement` 就是範本，照同樣模式加：

```ts
export async function getSelfcheck(
  email: string, semester: string,
): Promise<HealthSelfcheck | null> {
  const { data, error } = await supabase
    .from('hc_health_selfcheck')
    .select('*')
    .eq('student_email', email)
    .eq('semester', semester)
    .maybeSingle()
  if (error) throw error
  return data
}

/** 以 (student_email, semester) 為唯一鍵 upsert；每份量表各自送出，只更新自己那幾欄 */
export async function saveSelfcheck(
  row: Partial<HealthSelfcheck> & { student_email: string; semester: string },
): Promise<HealthSelfcheck> {
  return unwrap(
    await supabase
      .from('hc_health_selfcheck')
      .upsert(row, { onConflict: 'student_email,semester' })
      .select()
      .single(),
  )
}
```

**重要：七份量表是分次送出的**（學生可以分不同節課做）。所以：

1. 進頁時先 `getSelfcheck()` 讀回既有那一列，已完成的量表卡片顯示「已完成」
2. 每送出一份量表，只帶那一份的欄位去 upsert，**不要把沒做的欄位寫成 null 蓋掉別人**
3. `needs_followup` 每次送出都要**重算整列**（讀回目前值 → 併上這次的 → 重算），不能只看這一份

`semester` 用既有的 `semesterKey(student)`（`${academic_year}-${semester}`），和登記頁一致。

## 5. 紅旗規則（這段最重要，不能改）

```ts
needs_followup =
     (mood_scale   ?? -1) >= 10      // 心情溫度計 中度以上
  || (stress_level ?? -1) >= 6       // 壓力偵測站 6 項以上
  || (depression   ?? -1) >= 12      // 情緒自我檢視表 12 分以上
  || depression_critical === true    // 第 20 題勾選，不看總分
```

`depression_critical` 要**單獨存**，因為它和「分數高」的處理急迫度不同，教師端之後要用不同標記區分。

### 鐵則

1. **關懷文案是固定文字，絕不接 AI 生成**，也不要在這個情境給任何生活習慣建議。內容原封不動照抄原型的 `careHTML()`。
2. **不要對求助專線做保密性或通報與否的保證**。原型的文案刻意避開了這點，轉換時不要「補上」。
3. 學生端**只呈現中性用詞**，紅色警示只做在教師端（教師端本次不做）。
4. 心情溫度計的 ★「有自殺的想法」**不放線上**。原型在該頁有一句說明「這份量表還有第 6 題，我們課堂上一起做」，要保留。
5. 壓力偵測站的分級建議已改寫過，**不要改回課本原文**（課本原文 6–8 項寫「接受系統性的心理治療」、9 項以上寫「藥物治療」，對高中生不適用）。
6. 原型裡 `const DEBUG = false` 控制的除錯區塊，正式版**不要移植**。

## 6. 我的餐盤

定位是**教學活動，不是檢測**——不算分、不評價。首頁的活動區文案已經這樣寫了，請保留這個區分。

送出時寫進 `plate` jsonb：

```json
{"grain":2,"veg":2,"fruit":1,"prot":1,"milk":1.5,"nut":1,
 "water":1500,"sugar":0,"kcalTarget":2500,"matched":6}
```

`matched` 是通過幾條判定（0–7）。**餐盤不影響 `needs_followup`。**

食物庫裡連鎖店與學校午餐的熱量是官方公布值，**份數是教學換算**，原型的 `srcnote` 有註明出處與查核日，轉換時要一起帶過去顯示在畫面上。
