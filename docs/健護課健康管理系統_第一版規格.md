# 健護課健康管理系統・第一版規格

給 Claude Code 的開工文件。目標是下週上課前可用。

---

## 0. 範圍界定

第一版**只做**這三件事，其餘一律延後：

1. 學生端：身體數值登記頁（含自動計算、範圍檢核、送出後看到燈號）
2. 學生端：課本自我檢測頁
3. 教師端：全班進度看板

**不做**：AI 建議、照片上傳、SMART 目標、四週行動打卡、PDF 匯出。

## 2. 資料表

```sql
-- 身體量測（一位學生一學期可有多筆，期初/期中/期末）
create table health_measurement (
  id            uuid primary key default gen_random_uuid(),
  student_email text not null,
  semester      text not null,              -- 例：'115-1'
  measured_at   date not null default current_date,
  round         text not null default 'initial',  -- initial / mid / final

  machine_no    text,
  height_cm     numeric(5,1),
  weight_kg     numeric(5,1),
  body_fat_pct  numeric(4,1),
  visceral_fat  numeric(4,1),
  bmr_kcal      integer,
  body_age      integer,
  waist_cm      numeric(5,1),
  hip_cm        numeric(5,1),
  sbp           integer,
  dbp           integer,
  pulse         integer,
  spo2          integer,

  -- 各部位（必填，八項全部要求）
  subcut_whole  numeric(4,1), subcut_trunk numeric(4,1),
  subcut_arms   numeric(4,1), subcut_legs  numeric(4,1),
  muscle_whole  numeric(4,1), muscle_trunk numeric(4,1),
  muscle_arms   numeric(4,1), muscle_legs  numeric(4,1),

  created_at    timestamptz default now(),
  updated_at    timestamptz default now(),
  unique (student_email, semester, round)
);

-- 課本自我檢測
create table health_selfcheck (
  id             uuid primary key default gen_random_uuid(),
  student_email  text not null,
  semester       text not null,

  lifestyle      text,      -- 課本 P14 生活型態
  mood_scale     text,      -- P224 心情溫度計
  stress_level   text,      -- P232 壓力檢測站
  depression     text,      -- P247 憂鬱情緒檢核
  diet_type      text,      -- 飲食金字塔測驗結果

  -- 85210（課本 P30）
  h85210         jsonb default '{}'::jsonb,
  -- key: breakfast, sleep8, fruit5, water1500, exercise1h, screen_under2, no_sugar_drink

  daily_kcal     integer,   -- 學生自算的每日所需熱量
  water_target_ml integer,  -- 建議飲水量（可由體重自動算）
  water_actual_ml integer,  -- 目前實際飲水量
  fitness_note   text,      -- 健康適能自評

  needs_followup boolean default false,  -- 見第 5 節
  created_at     timestamptz default now(),
  updated_at     timestamptz default now(),
  unique (student_email, semester)
);
```

`semester` 欄位是學期切換的關鍵——換班不刪資料，只是新增新學期的列。

### 自動計算欄位（前端算，不存資料庫）

| 欄位 | 公式 |
|---|---|
| BMI | 體重 ÷ (身高公尺)² |
| 體脂重量 | 體重 × 體脂率 ÷ 100 |
| 腰臀比 | 腰圍 ÷ 臀圍 |
| 建議飲水量 | 體重 × 30～35 ml |

存原始值、算的時候現算，避免資料不一致。

## 3. 權限（RLS）

**這一段是安全的核心，不能省。**

```sql
alter table health_measurement enable row level security;
alter table health_selfcheck  enable row level security;

-- 學生只能讀寫自己的
create policy student_own on health_measurement
  for all using (auth.jwt() ->> 'email' = student_email)
  with check   (auth.jwt() ->> 'email' = student_email);

-- 教師可讀全部（用既有的 teacher 判定方式，沿用座位系統的做法）
create policy teacher_read on health_measurement
  for select using ( <既有教師判定條件> );
```

`health_selfcheck` 同樣兩條。

前端把別人的資料藏起來不算安全，一定要在資料庫這層擋。

## 4. 學生端頁面

登記頁的完整版面、欄位、自動計算、範圍檢核與燈號判讀，**請直接參考同資料夾的 `健康登記頁_原型.html`**，照著改成接 Supabase 的版本即可。

### 範圍檢核（打錯字擋在前面）

| 欄位 | 合理範圍 | 欄位 | 合理範圍 |
|---|---|---|---|
| 身高 | 130–210 cm | 腰圍 | 50–150 cm |
| 體重 | 30–150 kg | 臀圍 | 60–160 cm |
| 體脂率 | 3–50 % | 收縮壓 | 70–200 |
| 內臟脂肪 | 1–30 | 舒張壓 | 40–140 |
| 基礎代謝率 | 800–3000 kcal | 脈搏 | 35–160 |
| 身體年齡 | 10–80 歲 | 血氧 | 80–100 % |
| 皮下脂肪率 | 1–50 % | 骨骼肌率 | 10–70 % |

超出範圍不是擋死，是提示「請再確認一次機器上的讀數」，學生確認後仍可送出。

**全部 20 個欄位都是必填**（含皮下脂肪率與骨骼肌率各四項），少填就不能送出，進度列會顯示還差幾格。

### 燈號判定門檻【送出前請老師確認】

原型的 `RULES` 區塊已寫好，但有兩件事要先確認：

1. **BMI 目前用 18 歲以上成人標準**（18.5 / 24 / 27）。若班上有未滿 18 歲的學生，請改用衛福部「兒童及青少年生長身體質量指數建議值」的年齡別數字。
2. **腰臀比用男性標準**（0.90 / 0.95）。

用詞一律中性：不出現「異常」「高血壓」「肥胖」，也**不顯示任何目標體重或該減幾公斤**。

**紅色警示只做在教師端。** 學生端維持三色燈號與中性文字，不要把教師端的紅框、紅字或「需確認」標記帶進學生畫面。

## 5. 自我檢測頁的紅旗處理

心情溫度計、壓力檢測站、憂鬱情緒檢核是篩檢工具，不是普通題目。

- 學生選到高風險等第（例如心情溫度計「15 分以上，重度情緒困擾」）時：
  - `needs_followup` 設為 `true`
  - **教師看板立刻標示**
  - 學生端顯示**固定文案**：肯定他願意誠實回答、說明可以找誰談、附輔導室與 1925 資訊
- 這一段**絕對不要接 AI 生成**，也不要在這種情況下給生活習慣建議。

## 6. 教師端進度看板

一頁一個班，一格一個學生：

| 顏色 | 意思 |
|---|---|
| 灰 | 還沒登記 |
| 淺 teal | 已登記數值 |
| 深 teal | 數值＋自我檢測都完成 |
| 琥珀邊框 | `needs_followup = true`，需要關注 |

另外要有：

- 「未完成名單」一鍵列出，可寄提醒信（沿用座位系統既有的信件流程）
- 點學生進去看單筆完整資料
- 匯出 CSV（給你自己備份用）
