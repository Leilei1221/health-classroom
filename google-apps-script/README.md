# Supabase → Google Sheets 點名同步（Google Apps Script）

把健護課系統的出缺席與上課表現寫進課室紀錄試算表，每班一個分頁。

## 部署步驟

### 1. 建立指令碼（必須綁在試算表上）

開啟目標試算表 → **擴充功能 → Apps Script**。

一定要用這個方式建立，不能開獨立的指令碼專案 —— 選單（`onOpen`）只有綁定在
試算表上的指令碼才會出現。

把 `Code.gs` 的內容整份貼進去，取代預設的 `myFunction`，存檔。

### 2. 放入 service_role key

Apps Script 編輯器左側 **專案設定（齒輪）→ 指令碼屬性 → 新增指令碼屬性**：

| 屬性 | 值 |
|---|---|
| `SUPABASE_SERVICE_KEY` | 你的 service_role key |

> service_role key 會繞過所有 RLS，等同資料庫的最高權限。
> 只放在這裡，不要貼進程式碼、不要進版控、不要分享試算表編輯權給不該有的人。
> 若曾經外流過（例如貼在對話或訊息中），到 Supabase 後台輪替一把新的。

### 3. 確認連線

編輯器上方函式選單選 **`testConnection`** → 執行。
第一次會跳授權（需要存取試算表與外部服務），同意即可。

執行紀錄應出現「連線正常，讀到 N 個班級：…」。

### 4. 手動同步

回到試算表，重新整理頁面，功能表列會多一個 **「健護課同步」**：

| 選單項目 | 作用 |
|---|---|
| 同步今天的點名 | 把今天的課堂寫進各班分頁 |
| 同步指定日期… | 補寫某一天（輸入 `YYYY-MM-DD`） |
| 重算所有統計欄 | 只重算右側統計，不新增課堂欄 |
| 安裝每日 18:00 自動同步 | 建立定時觸發器 |
| 移除自動同步 | 刪除該觸發器 |

### 5. 開啟自動同步

點 **「安裝每日 18:00 自動同步」**。之後每天 18:00 會自動跑當天的點名。

時區以指令碼專案設定為準，請確認是 `Asia/Taipei`
（專案設定 → 時區）。

## 寫入規則

**版面**

- 第 1 列：合併主標題「`日期 班級名`」（例：`9/3 308`）橫跨 4 欄
- 第 2 列：子標題「`第X節 時間`、`特殊狀況`、`第Y節 時間`、`特殊狀況`」
- 第 3 列起：學生資料

一個日期區塊固定 4 欄（兩個節次）。當天只有一節課時，第二組欄位留空。

**新欄位插在哪裡**

插在「上課表現」統計區**之前**，不是接在整張表最後面。

現有分頁的統計區右邊還有作業成績、評語、作業次數、總成績等欄位，
直接往最右邊加會把版面接錯。

**不覆蓋舊資料**

同步前會先找第 1 列有沒有同名的「`日期 班級名`」標題，有就整個跳過。
因此重複執行、或手動與定時觸發器都跑到同一天，都不會重複寫入。

**出缺席**

| 資料庫 | 試算表 |
|---|---|
| `present` | （空白） |
| `late` | 遲到 |
| `absent` | 曠課 |
| `leave` | 請假 |
| `official` | 公假 |

**特殊狀況**

由 `hc_performance_records` 產生，多筆以「、」相連。
項目名稱對照試算表既有用語：使用手機→玩手機、趴睡→睡覺、講話干擾→聊天。
加分項目附上分數，例如 `回答問題(+1)`。

**統計欄**

每次同步後整班重算（從資料庫重讀，不做增量累加，所以不會愈加愈多）：

| 欄位 | 內容 |
|---|---|
| 曠課 / 遲到 | 該狀態的次數 |
| 玩手機 / 睡覺 / 聊天 | 對應表現項目的次數 |
| 其他 | 其餘表現項目的次數 |
| 成績 | `90 + 出缺席扣分 + 上課表現加扣分` |

成績基準 90 分是從現有分頁反推的：0曠0遲=90、2曠=80、1曠1遲=83、4曠=70、
1曠2遲=81，全部符合「90 − 曠課×5 − 遲到×2」，而 5 與 2 正是資料庫的扣分值。
要改基準分，調 `CONFIG.BASE_SCORE`。

## 相容性

程式碼不假設欄位位置，一律以標題名稱定位。已對現有試算表的 14 個分頁實測：

- 有分頁在座號前面多一欄「班級」→ 正確抓到座號在第 2 欄
- 有分頁的統計區多一欄「留垃圾」→ 正確跳過，不會被覆蓋
- 各分頁欄數從 43 到 90 不等 → 插入位置皆正確

座號比對會正規化（「01」與「1」視為同一人）。

## 需要調整的設定

`Code.gs` 最上方的 `CONFIG`：

| 設定 | 說明 |
|---|---|
| `CLASS_FILTER` | 要同步的班級，預設 `['305','306','307','308','309']`；留空 `[]` 表示全部 |
| `PERIOD_TIMES` | 節次對應時間。已由現有分頁確認第6節=14:10、第7節=15:10，其餘依此推，若與實際鐘點不符請改這裡 |
| `BASE_SCORE` | 成績基準分，預設 90 |
| `PERF_ALIAS` | 表現項目名稱對照 |

## 已知限制

- 分頁不存在時會自動建立，但只含固定 4 欄與統計區；作業成績、評語那些欄位不會自動產生
- 「未點名」與「出席」在試算表上都是空白，兩者無法區分（依既有格式的規則）
- 一天超過兩節課時只會寫入前兩節
